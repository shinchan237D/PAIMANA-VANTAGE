# Hackathon Handoff

## Start on Windows

Run:

`final\\scripts\\START_SENTINEL.bat`

The launcher starts the bundled FastAPI backend on `127.0.0.1:8000`, installs frontend packages on first run if needed, starts Vite on `127.0.0.1:5173`, and opens the app.

## Demo path

1. National Overview — establish scale, April snapshot and national pulse.
2. Portfolio Map — show geographic distribution and state-centroid transparency.
3. Sentinel Watchlist — surface the highest attention records.
4. Project — inspect trajectory, commitment stress and evidence.
5. Data Trust Center — show provenance, coverage and QA observations.
6. National Brief — show the exportable summary surface.

## Important semantics

Sentinel attention states are deterministic monitoring signals. They are not calibrated probabilities and should not be presented as predictions of failure.
