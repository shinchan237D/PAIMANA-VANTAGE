# PAIMANA SENTINEL — Hackathon Release Notes

Current build: Step 05 · 5.0.0-step05

The application is intended to demonstrate a source-aware infrastructure monitoring workflow using the bundled April 2026 assessment snapshot and stored historical snapshots.

### Demo path
1. National Overview
2. Portfolio Map
3. Select a project marker
4. Open Project Intelligence
5. Diagnose / Stress / Historical recovery
6. Generate the National Monitoring Brief

### Controls
- `Ctrl/Cmd+K`: global search
- `D`: presentation route
- `M`: map
- `W`: watchlist
- `B`: brief
- `Esc`: close active overlay

### Important semantics
Project attention values are reference-class / rule-based analytical signals, not validated probabilities. Location labels distinguish exact source GPS from administrative context.
