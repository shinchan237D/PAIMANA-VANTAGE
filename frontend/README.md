# PAIMANA Sentinel Frontend — Step 01

React + Vite frontend for the April 2026 PAIMANA Sentinel assessment build.

## API

Default: `/api/v3` via the Vite development proxy.

Override with:

`VITE_API_URL=http://127.0.0.1:8000/api/v3`

## Run

`npm install`

`npm run dev`

## Build

`npm run build`

The shipped Windows startup scripts install dependencies automatically on first run.
